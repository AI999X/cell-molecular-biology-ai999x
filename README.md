# Cell and Molecular Biology (cell-molecular-biology-ai999x)

[![tests](https://github.com/AI999X/cell-molecular-biology-ai999x/actions/workflows/ci.yml/badge.svg)](https://github.com/AI999X/cell-molecular-biology-ai999x/actions/workflows/ci.yml) [![PyPI](https://img.shields.io/pypi/v/cell-molecular-biology-ai999x)](https://pypi.org/project/cell-molecular-biology-ai999x/) [![Hugging Face](https://img.shields.io/badge/%F0%9F%A4%97-Hugging%20Face-yellow)](https://huggingface.co/AI999X/cell-molecular-biology-ai999x)

Cell and Molecular Biology covers membranes and diffusion, osmosis and membrane potentials, cell growth and the cell cycle, DNA and RNA melting temperatures and quantification, sequences, PCR and qPCR, gene expression, enzyme kinetics, inhibition and binding, buffers and dilutions: 104 calculations in 10 topics, each with its formula, its steps and its units, and a plain reason instead of a number when an input is missing or out of range. One compiled engine, four ways to use it: the desktop app, the command line, the browser and Python. Everything runs on your own computer, offline.

[![The Cell and Molecular Biology desktop app: Nernst equilibrium potential of an ion across a cell membrane, with its worked example and live scene](https://www.ai999x.com/?ax_shot=cell-molecular-biology-ai999x/hero.webp)](https://www.ai999x.com/models/cell-molecular-biology-ai999x/)

## Ask in words: 15 examples

Each question below was asked on this release; the comment under it is the line it printed.

```python
import cell_molecular_biology_ai999x as cell_molecular_biology

a = cell_molecular_biology.ask(
    "Absorbance ratios: A260 = 0.9, A280 = 0.5, A230 = 0.42"
)
print(a.outcome, a.values)
# SOLVED {'ratio_260_280': 1.8, 'ratio_260_230': 2.14285714286}

a = cell_molecular_biology.ask(
    "Cell volume after an osmotic change: V0 = 90 fL, b = 40%, osm0 = "
    "300 mOsm/L, osm1 = 600 mOsm/L"
)
print(a.outcome, a.values)
# SOLVED {'V': 6.3e-17, 'V_fL': 63.0, 'ratio': 0.7}

a = cell_molecular_biology.ask(
    "Specimen size from a micrograph: image_size = 12 mm, M = 400 x"
)
print(a.outcome, a.values)
# SOLVED {'size': 3e-05, 'size_um': 30.0, 'M_image': 400.0}

a = cell_molecular_biology.ask(
    "Hemocytometer cell count: counts = [52, 48, 55, 45], dilution = 2"
)
print(a.outcome, a.values)
# SOLVED {'mean_count': 50.0, 'cells_per_mL': 1000000.0}

a = cell_molecular_biology.ask(
    "Basic melting temperature: seq = AGCGGATAACAATTTCACACAGGA"
)
print(a.outcome, a.values)
# SOLVED {'Tm': 53.9666666667, 'gc_percent': 41.6666666667, 'length': 24}

a = cell_molecular_biology.ask(
    "Ki from IC50: mode = competitive, IC50 = 10 uM, S = 100 uM, Km = "
    "50 uM"

a = cell_molecular_biology.ask("Fraction bound: L = 10 nM, Kd = 5 nM")
```

## Source and releases

This repository holds the installable source of each release, exactly as published on [PyPI](https://pypi.org/project/cell-molecular-biology-ai999x/) (`pip install .` builds it). Releases are tagged `v1.6.7`; the [GitHub release](https://github.com/AI999X/cell-molecular-biology-ai999x/releases/tag/v1.6.7) carries the wheel, the desktop app and the command-line program for Windows and Linux, and their checksums.

## Build the program from source

`rust/` holds the Rust source of the `cell-molecular-biology` command-line program and browser module: the AI999X engine (`rust/ax-engine`), this model (`rust/cell-molecular-biology`) and its data (`rust/models/cell_molecular_biology/pack.json`). With Rust 1.80 or later:

```bash
cd rust
cargo build --release -p cell-molecular-biology-ai999x
./target/release/cell-molecular-biology --help
cargo test -p cell-molecular-biology-ai999x
```
